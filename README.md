# Ecommerce Product Discovery Assessment Framework

This project is an MDE-managed consulting asset for evaluating ecommerce product discovery experiences across search, autocomplete, browse navigation, filtering, recommendations, mobile usability, and realistic customer journeys.

Boxercraft is the first validation target and case study. The framework must remain reusable across ecommerce verticals such as apparel, industrial suppliers, auto parts, distributors, wholesalers, home services catalogs, and specialty retailers.

Start with `MISSION.md`, then follow `.mde/state.json` and `.mde/validation-strategy.json`.
