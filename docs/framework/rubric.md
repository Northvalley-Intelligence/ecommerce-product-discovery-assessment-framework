# Ecommerce Product Discovery Rubric

The rubric in `framework/assessment-rubric.json` is the source of truth for Generation 1.

## Assessment Areas

- Search
- Autocomplete
- Browse Navigation
- Filters And Faceted Navigation
- Recommendations And Related Discovery
- Mobile Experience
- Product Discovery Journey Analysis

## Finding Standard

Every report finding must include:

- Observation
- Evidence
- Severity
- Customer impact
- Business impact
- Recommendation

Evidence must record the source, capture date, access context, locator, summary, and freshness status. If evidence is unavailable because the workflow is authenticated or client-private, record an access limitation instead of treating the missing evidence as a site defect.

## Scoring Standard

Scores use a 0-100 scale. A score is not a finding; it is a summary of evidence-backed findings and observed customer effort.

Scoring dimensions:

- Precision
- Recall
- Ranking Quality
- Diversity
- Query Understanding
- Robustness
- Coverage
- Recovery
- User Effort

## Boxercraft Pilot Rule

Use Boxercraft to validate the framework, not to narrow the framework to one apparel site. Any rubric change learned from the pilot must state whether it is reusable across verticals, apparel-specific, wholesale-specific, or only Boxercraft-specific.
