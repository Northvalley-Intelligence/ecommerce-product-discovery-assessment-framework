\ReportSection{How this was measured}

\begin{itemize}\setlength{\itemsep}{1pt}\setlength{\parskip}{0pt}\setlength{\topsep}{2pt}

\item \textbf{Real shopper search, no production load.} Each store was evaluated on its live on-site search --- the engine shoppers actually use --- with bounded, paced reads (about one per second, a plain inspection user-agent, robots respected). \textbf{No crawling, no scraping, and no load on production.}

\item \textbf{Graded relevance.} Every returned product was scored 0--3 for relevance by a local large language model (Meta Llama 3.2 3B, temperature 0, reproducible), summarized as NDCG (0--1).

\item \textbf{Demand overlay.} Each term is joined to Google Keyword Planner monthly search volume, so failures are ranked by real demand.

\item \textbf{Scope.} 50 shopper search terms across four query datasets. A quick read, not an exhaustive audit; reliability rises with search-API access and real query logs.

\end{itemize}

\begin{itemize}\setlength{\itemsep}{1pt}\setlength{\parskip}{0pt}\setlength{\topsep}{2pt}

\item \textbf{Attributes are broken on both.} \qq{walnut dining table}, \qq{oak dining table}, \qq{marble coffee table}, \qq{velvet chair}, \qq{cane dining chair} all return \textbf{0} on both stores, despite the catalog stocking marble, oak, walnut, leather and cane.

\item \textbf{Natural-language intent is dead on both.} \qq{furnish a living room}, \qq{dining set for 6}, \qq{home office}, \qq{small space seating}, \qq{reading chair} all return \textbf{0}. Shoppers who describe what they want, rather than name a product, hit a wall.

\item \textbf{The migration swapped one flaw for another.} The legacy storefront is fuzzy (14\% off-target); the new store is so strict it returns nothing for common words like \qq{kitchen stool}, \qq{accent chair} and \qq{coffee table}.

\end{itemize}
