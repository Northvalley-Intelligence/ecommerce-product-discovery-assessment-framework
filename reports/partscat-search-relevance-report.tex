\ReportSection{The fix --- a data change, not an algorithm rewrite}
\vspace{-2pt}Index the competitor interchange numbers Caterpillar \emph{already publishes} so the search box resolves them --- the same way Cat\textquotesingle s own numbers already redirect to the product. A shopper holding a competitor number is the highest-intent buyer on the site. Today the search matches it as a digit string, so instead of the filter they get bearings, brackets and bolts --- or one confidently wrong product page.
