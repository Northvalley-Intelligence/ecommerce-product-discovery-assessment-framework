\ReportSection{Summary}

\ReportDarkCard{The headline --- search fixes at scale}{Across 83 demand-weighted search terms, poor relevance puts an estimated \textbf{\$275K/year} at risk. Applied to the \textbf{top 1,000} search terms, that projects to \textbf{\$3.3M per year} (range \$853K--\$8.3M) --- the prize for fixing search. Modeled on real Google demand; assumptions and full math in the appendix.}

\vspace{5pt}

\ReportDarkCard{Strong, with focused gaps}{Target search handles the everyday well --- synonyms, brand and product-name queries, and product types all return relevant results (overall grade 1.76/3 across 110 terms). The clear weakness is compositional, natural-language intent (job-function queries grade just 1.33/3): when a phrase does not map to a single category, the engine keyword-matches a token and returns a plausible aisle rather than understanding the request.}

\vspace{4pt}\ReportBody{The intent gap is specific: \qq{move into a new house} returns romance novels and toy food trucks; \qq{set up a home theater} mixes soundbars with women\textquotesingle s pajamas; \qq{furnish a living room} returns vases (not furniture). But it handles intent well when the phrase maps to a real category --- \qq{healthy snacks for kids}, \qq{home gym equipment}, \qq{organize my kitchen} all work. A second, narrower gap is regional/substring synonyms: the engine substring-matches rather than mapping the word, so \qq{pop} and \qq{popsicle} return Pop-Tarts, \qq{ice lolly} returns mints, and \qq{jumper} returns baby activity jumpers. It nails the everyday --- loveseat, stanley tumbler, lego star wars, instant pot, decorate a nursery, stainless steel cookware set, nintendo switch, all in motion --- and brand queries redirect to curated brand pages. Attribute queries return the right product type but do not always honor the exact attribute.}\par

\ReportSection{How this was measured}

\begin{itemize}\setlength{\itemsep}{1pt}\setlength{\parskip}{0pt}\setlength{\topsep}{2pt}

\item \textbf{Real shopper search, no production load.} Each term was run on Target\textquotesingle s live search page and the top results read from what the browser rendered --- bounded and paced, no crawling or scraping. Reading the raw search API at volume triggers bot protection, which we did not bypass.

\item \textbf{Graded relevance.} Every returned product was scored 0--3 for relevance by a local large language model (Meta Llama 3.2 3B, temperature 0, reproducible), summarized as NDCG (0--1) and mean grade. 721 product judgments across 110 terms and five query types.

\item \textbf{Why grade, not coverage.} A big-box engine returns something for almost anything, so coverage and NDCG (internal ordering) stay high; mean grade is the honest signal of whether results match intent.

\item \textbf{Caveat.} Results were read from Target\textquotesingle s organic search (sponsored and \qq{recommended} carousel tiles excluded); the lowest-scoring terms were re-verified against the live site to rule out capture artifacts. A production run would use the full organic search API at scale.

\end{itemize}
